Common Questions

How is this different from a standard security audit? +

Security is just 1 of 8 dimensions. We also assess accuracy/drift, cost efficiency, observability, reliability, human-in-loop design, scalability, and regulatory compliance. Most security audits miss the AI-specific attack surfaces like prompt injection, tool abuse, and data exfiltration through agent outputs.

What if we only have 1-2 agents in production? +

The audit scales to your deployment. Fewer agents means deeper analysis per agent. Many of our highest-value findings come from single-agent deployments where architectural decisions have outsized impact. Start with the free diagnostic and we will tell you honestly whether a full audit is warranted.

Do you need access to our codebase? +

It depends on the depth of analysis needed. We can work with architecture diagrams, API documentation, and stakeholder interviews for a strategic assessment. For a technical deep-dive, read-only access to relevant repositories and monitoring dashboards produces the most actionable findings. All covered under NDA.

Can we implement the fixes ourselves? +

Absolutely. The remediation roadmap is designed to be actionable by your team. Every finding includes the specific steps, effort estimate, and expected impact. If you want help implementing, we offer managed operations at $15K/month, but it is entirely optional.

Why only 3 clients per quarter? +

Quality. Each audit gets Aurelio Dioval's personal involvement. Scaling beyond 3 would mean delegating core analysis, and that is where audit quality degrades. We would rather turn away work than deliver a shallow assessment.
